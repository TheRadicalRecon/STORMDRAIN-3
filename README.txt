STORMDREIGN 1.10.50.02 — INSTALLATION
1. Extract this ZIP in Files on iPhone (tap the ZIP).
2. Sign in at github.com and create a public repository named stormdrain.
3. Upload all website files (except README.txt) individually to the repository root (not the ZIP or a containing folder). Commit changes.
4. Settings > Pages > Deploy from a branch > main > / (root) > Save.
5. Open https://YOUR-USERNAME.github.io/stormdrain/ in Safari after deployment.
6. Share > Add to Home Screen > Open as Web App (if offered) > Add.
Rotate your phone for a larger game. Tap to jump, hold to jump higher.
Offline support requires a successful initial online load. Local saves stay on the same browser/app installation; clearing website data can erase them. Nine soundtrack files are bundled.
For updates replace website files and change the cache version in sw.js.
